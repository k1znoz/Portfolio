# Notes RGPD et accessibilite (RGAA)

## RGPD
- Donnees collectees via formulaire:
  - nom
  - email
  - message
- Finalite:
  - repondre a la demande de contact de l'utilisateur
- Consentement:
  - case obligatoire avant soumission
- Minimisation:
  - seules les donnees strictement necessaires sont demandees
- Limite actuelle:
  - stockage local en mode demonstration (pas de transmission serveur)

## Accessibilite (RGAA)
- Formulaire semantique avec labels explicites.
- Messages d'etat et d'erreur exposes via role status/alert.
- Navigation clavier conservee et champs requis identifies.
- Ameliorations futures recommandees:
  - audit axe-core automatise
  - revue contraste complete sur tous themes
  - tests lecteurs d'ecran (NVDA/VoiceOver)
